Why it exists

Every assistant forgets the work you already did.

Cortex turns scattered decisions, notes, project context, people, and open loops into a reusable memory layer. Save once, review what matters, then paste or expose the right context to the AI tool you already use.

The product loop

Capture, review, reuse, return.

The first release is intentionally simple. It focuses on the one habit that makes AI memory valuable every day.

01

Save a clipboard snippet, quick note, browser page, file, or AI conversation.

Trust controls

Private by default, useful on purpose.

Cortex stores memory on the user's Mac, exposes local diagnostics, and lets users choose what agents can read, write, export, or repair.

Local vault

Readable JSON records and a rebuildable SQLite index live on disk.

Review first

New captures can wait in the inbox until the user approves them.

Agent permissions

Reads, writes, exports, and maintenance actions are controlled separately.

Reliability report

Health checks, backup recency, and repair actions are visible in the app.
