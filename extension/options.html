◆ Cortex Memory

Connect this browser to your local Cortex server. Everything stays on loopback.

Default is http://127.0.0.1:8766. Use the base URL shown when you paired in the Cortex app.
Open the Cortex macOS app, pair a browser extension, and paste the token it gives you. The token is stored in your browser's sync storage and sent only to the server URL above.
Privacy: this extension talks only to the Cortex server URL you configure (your local machine by default). Your token never leaves the browser except as a Bearer header to that URL.
