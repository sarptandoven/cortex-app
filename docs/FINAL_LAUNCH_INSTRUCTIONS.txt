PART 0 — WHAT EXISTS TODAY (so you know what you are NOT building)
================================================================================

Backend (Python, FastAPI hosted plane + stdlib local server):
- Multi-tenant: per-user isolated SQLite shards (16-bucket mode), provisioning,
  suspension, deletion, quotas, rate limits. Admin token cannot impersonate
  users in sharded mode (tested).
- Accounts: email+password (argon2id), Google + GitHub OAuth (full id-token
  verification), opaque rotating sessions (cxs_/cxr_) with family revocation
  on refresh-token reuse, enumeration-resistant responses, never-auto-link
  identity rules, invite/claim flow for pre-account users.
- Per-user encryption: envelope encryption (AES-256-GCM), per-user keys
  wrapped by a root KEK, tenant-bound (a ciphertext moved to another user's
  row fails to decrypt), crypto-shredding on account delete (every backup
  ever taken becomes unreadable for that user). Connector credentials are
  encrypted first; broader content encryption is phased (PART 11).
- Web account front door: /account/signup, /account (login), /account/verify,
  /account/reset, /account/home (mint/revoke API + MCP tokens, delete
  account), served by the backend itself. No separate frontend to deploy.
- Email: SMTP sender for verification/reset links (Postmark/SES/any SMTP).
  Beta mode (CORTEX_AUTH_AUTOVERIFY=1) needs NO email at all.
- Agent surface: curated 7-tool MCP core + /v1/context assembly engine,
  cite-or-abstain answers, whole-person map. This is the product.
- Retrieval quality: 136-case eval corpus gating CI; real on-device
  embeddings (model2vec) — zero per-query API cost, privacy-consistent.

macOS app (Swift):
- Full local-first product (works with no account, no network).
- "Sign in to Cortex Cloud" in Connections & Privacy: email/password or
  browser sign-in (Google/GitHub via the app/start+poll flow), refresh token
  in Keychain, automatic session refresh — all hard-gated so local mode is
  byte-identical when signed out.
- Build + packaging: macos/build.sh (dev), macos/package_release.sh
  (DMG/zip/checksums/manifest; --production adds Developer ID signing +
  notarization + stapling — tooling is COMPLETE, needs only your cert).

Deploy kit (deploy/):
- push.sh (one command from your Mac), bootstrap.sh (hardening, Caddy TLS,
  secrets generation, systemd, backups), update.sh (deploy w/ auto-rollback),
  backup.sh (nightly WAL-safe snapshots), Caddyfile, cortex.env.example,
  systemd units. All tested for shell syntax; the server profile was
  rehearsed end-to-end locally (uvicorn, bucket shards, KEK, real signup ->
  login -> capture -> cited answer -> token mint).

Site (site/):
- Static landing + downloads + an ACCURATE privacy page (drafted honestly,
  marked "pending legal review"). Deployable to any static host.
