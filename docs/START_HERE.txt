A1. CREATE THE SERVER (~5 min)  [you: form + card]
    console.hetzner.cloud -> new project "cortex-prod" -> Add Server:
      Ubuntu 24.04, type CX32, add your SSH key, tick "Backups". Note the IP.
    OR hand to agent: give a Hetzner API token; the agent creates it for you.

A2. POINT DNS (~2 min + propagation)  [you]
    In trydoppl.com DNS add:  A  |  name: api  |  value: <SERVER-IP>
    Wait until:  dig +short api.trydoppl.com   returns the IP.
    OR hand to agent: give a Cloudflare DNS token; the agent adds it.

A3. DEPLOY (~5 min)  [you: one command | OR fully hand to agent]
    From this repo on your Mac:
      deploy/push.sh root@<SERVER-IP> api.trydoppl.com

    backups, and PRINTS your admin token + encryption KEK ONCE.
    OR hand to agent: with the Hetzner + Cloudflare tokens the agent runs A1–A3
    end to end and reports the printed secrets to you privately.

A4. SAVE THE SECRETS + ESCROW THE KEK (~5 min)  [you — cannot delegate]
    Copy the admin token (cxop_...) to your password manager. Copy the KEK
    (also at /etc/cortex/kek) to (1) your password manager AND (2) a separate
    offline place NOT with the server backups. See docs/runbooks/KEK_ESCROW.md.
    WHY: lose the KEK = all encrypted data is unrecoverable. This is the one
    step you must physically own.

A5. VERIFY (~2 min)  [you or agent]
    curl https://api.trydoppl.com/health   -> {"status":"ok",...}

      Homepage https://trydoppl.com

    Put the client id/secret into /etc/cortex/cortex.env
    (CORTEX_OIDC_GITHUB_CLIENT_ID / _SECRET) then:

B3. APPLE DEVELOPER ID CERT (~15 min + up to 1–2 wk if switching to an Org

    developer.apple.com -> Certificates -> "+" -> "Developer ID Application";
    make the request in Keychain Access, install the cert. Create an app-specific

      xcrun notarytool store-credentials cortex-notary \
        --apple-id "<you>" --team-id "<TEAMID>" --password "<app-pw>"

B4. GOOGLE SIGN-IN REVIEW (~1–2 wk)  [you]

    (GitHub already covers social login in the meantime.)

B5. EMAIL PROVIDER + DOMAIN WARM-UP (~30 min + days of warm-up)  [you]

    DNS records (the agent can add these if you gave it the Cloudflare token).
    Start sending a little real mail now so the domain isn't "cold" at launch.

B6. BILLING ACCOUNT — only if charging (~days, KYC)  [you]
