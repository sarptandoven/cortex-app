Why it exists

Every assistant forgets the work you already did.

Cortex builds a private adaptation layer from chats, email, notes, writing, decisions, and messages. It shows what the model covers, what still needs signal, and lets approved AI tools retrieve scoped memory instead of guessing.

The product loop

Signal, review, access, return.

The first release focuses on the habits that make a personal model trustworthy: add sources, approve useful signals, and let AI tools access only what you allow.

01

Signal

Import selected exports, folders, and files from chats, email, notes, messages, docs, writing, bookmarks, calendars, contacts, and work tools.

02

Review

Approve useful signals, archive noise, and keep the memory layers trustworthy.

03

Access

Use a cited adaptation profile or connect a supported local tool before starting work in an assistant.

04

Return

Open Cortex to see coverage, weak layers, and the next source that would improve the model.

Trust controls

Private by default, useful on purpose.

Cortex stores memory on the user's Mac, shows what is covered, and lets users choose what connected tools can read, write, export, or repair.

Local vault

Readable JSON records and a rebuildable SQLite index live on disk.

Review first

New captures can wait in the inbox until the user approves them.

Agent permissions

Reads, writes, exports, and maintenance actions are controlled separately.

Reliability report

Health checks, backup recency, and repair actions are visible in the app.
