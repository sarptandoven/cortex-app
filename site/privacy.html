Privacy

Cortex local beta privacy

Cortex is built as a local-first macOS beta. The first release is designed to store memory on the user's Mac and avoid a hosted account or cloud database.

What Cortex stores

  • Memories the user approves from connected services, direct local integrations, quick notes, browser captures, or AI-tool workflows.
  • Extracted memories, tasks, entities, topics, graph edges, settings, audit events, and backups.
  • A readable local memory folder plus a rebuildable search index for search and map views.

Where data lives

  • By default: ~/Library/Application Support/Cortex/Cortex.vault/.
  • The user can choose a different memory folder during setup.
  • The app does not require a cloud service for the local beta.

What Cortex reads

  • Cortex reads clipboard content only when the user clicks a capture action or uses the capture hotkey.
  • Cortex reads connected account data only after the user signs in or grants an explicit local integration permission.
  • Cortex does not crawl cloud apps, email accounts, browser history, or Messages without a connected account or approved local integration.
  • Cortex does not record the screen, listen through the microphone, or capture ambient activity in this beta.

AI tool sharing

  • Context is shared when the user copies chat context or enables a direct local AI integration.
  • New local memory folders start with review enabled, connected AI tool reads enabled for retrieval, and redaction enabled.
  • Connected AI tool writes, exports, maintenance, and destructive actions are disabled until the user opts in.
  • Redaction can mask common tokens, secrets, emails, and long account-like numbers before context is shared.
  • Support bundles omit raw capture text, memory bodies, copied chat context, and exported user data.

Current beta boundaries

  • No account system, billing, hosted sync, or team workspace is included in the local beta.
  • Account connectors are staged by service readiness; Advanced/Fallback recovery intake is support-only and not the normal product path.
  • No analytics service is required by the static landing page.
  • Public distribution still needs Developer ID signing, notarization, hosted HTTPS downloads, and a formal privacy policy review.
