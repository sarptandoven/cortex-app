Cortex local beta privacy

Cortex is built as a local-first macOS beta. The first release is designed to store memory on the user's Mac and avoid a hosted account or cloud database.

What Cortex stores

  • Captures the user explicitly saves through clipboard, quick note, file import, browser capture, or AI-tool workflows.
  • Extracted memories, tasks, entities, topics, graph edges, settings, audit events, and backups.
  • A readable local vault plus a rebuildable SQLite index for search and graph views.

Where data lives

  • By default: ~/Library/Application Support/Cortex/Cortex.vault/.
  • The user can choose a different vault folder during setup.
  • The app does not require a hosted backend for the local beta.

What Cortex reads

  • Cortex reads clipboard content only when the user clicks a capture action or uses the capture hotkey.
  • Cortex reads selected files, folders, export bundles, or local database copies only when the user chooses or drops those sources.
  • Cortex does not crawl cloud apps, email accounts, browser history, or Messages automatically in this beta.
  • Cortex does not record the screen, listen through the microphone, or capture ambient activity in this beta.

AI tool sharing

  • Context is shared when the user prepares an approved-memory handoff or enables a local AI integration.
  • Trust controls can block agent reads, writes, exports, and maintenance actions.
  • Redaction can mask common tokens, secrets, emails, and long account-like numbers before context is shared.

Current beta boundaries

  • No account system, billing, hosted sync, or team workspace is included in the local beta.
  • No live OAuth/API connectors are included yet; Stage 1 import is based on user-selected local exports and files.
  • No analytics service is required by the static landing page.
  • Public distribution still needs Developer ID signing, notarization, hosted HTTPS downloads, and a formal privacy policy review.
