# Cortex by Doppl Publish Manifest

This repository contains the local-first Cortex by Doppl macOS app source, packaging scripts, landing page, release docs, and archived packaged app artifacts.

## Included Release Artifacts

- `release-artifacts/app-store/Doppl-AppStore-0.1.0-1.pkg`
  - Mac App Store / TestFlight upload candidate generated by `macos/package_app_store.sh`; upload completion is not asserted by this repository.
  - Bundle ID: `com.cortex.doppl`
  - Team ID: `P4H96J3VXY`
  - Package SHA-256: `90608d1df390653544011e74fdbff08a1462abb6bf178f6c48d71423ca4fa588`
- `release-artifacts/app-store/app-store-build-report.json`
  - Build report generated by `macos/package_app_store.sh`.
- `release-artifacts/app-store/Doppl-AppStore-0.1.0-1.entitlements.plist`
  - Signed app entitlements captured from the package build.
- `release-artifacts/direct-mac/Cortex-0.1.0-1.dmg`
  - Direct-distribution local beta DMG artifact.
- `release-artifacts/direct-mac/Cortex-0.1.0-1.app.zip`
  - Direct-distribution local beta app zip artifact.
- `release-artifacts/direct-mac/latest.json`
  - Relocatable update-feed manifest for the archived direct-download artifacts.
- `release-artifacts/SHA256SUMS.txt`
  - Checksums for the packaged binary artifacts in this repo.

## What Is Excluded

The repository intentionally excludes transient and local-only data:

- `.env`
- local vault data under `backend/data/`
- `macos/build/`
- Python bytecode and cache folders
- `.DS_Store`

## Useful Commands

Build the local app:

```bash
./macos/build.sh
open macos/build/Cortex.app
```

Build the App Store package:

```bash
./macos/package_app_store.sh
```

Run backend tests:

```bash
python3 -m unittest discover backend/tests
```

Validate committed beta docs and manifests:

```bash
python3 scripts/check_docs_current.py
python3 scripts/validate_update_manifest.py release-artifacts/direct-mac/latest.json
python3 scripts/validate_update_manifest.py site/downloads/latest.json
```
