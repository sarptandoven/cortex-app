## What Is Excluded

The repository intentionally excludes transient and local-only data:

- `.env`
- local memory data under `backend/data/`
- `macos/build/`
- Python bytecode and cache folders
- `.DS_Store`

## Useful Commands

Build the local app:

```bash
./macos/build.sh
open macos/build/Cortex.app
```

Build the App Store package:

```bash
./macos/package_app_store.sh
```

Run backend tests:

```bash
python3 -m unittest discover backend/tests
```

Validate committed beta docs and manifests:

```bash
python3 scripts/check_docs_current.py
python3 scripts/validate_update_manifest.py site/downloads/latest.json
```
